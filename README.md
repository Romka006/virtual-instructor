# Страница продукта «Виртуальный инструктор»

Опубликована: https://romka006.github.io/virtual-instructor/
Инструкция по обновлению: ../docs/GITHUB-PAGES.md

Не лендинг из шаблона, а личная страница: рассказ от первого лица, как продукт
появился и почему его стоит поставить школе. Статика: HTML + CSS + один JS,
без сборки, зависимостей и внешних шрифтов.

## Посмотреть

Откройте `index.html` в браузере — работает с диска (`file://`).

## Выложить

Скопировать папку `landing/` на хостинг: в `public_html`, на отдельный
поддомен или в любую статику.

## Что заменить

1. **Приём заявок.** В `app.js` наверху `LEAD_ENDPOINT`. Пусто — форма пишет
   в localStorage и показывает «записал» (демо-режим). Укажите адрес —
   например `/api/index.php?module=home&action=submit_lead` — и заявки
   начнут уходить POST с JSON `{ name, school, phone }`.
2. **Города и цифры** — в тексте `index.html`: шапка, обложка, раздел 04.
3. **Скриншоты** — `assets/home.png`, `assets/pdd.png`, `assets/chat.png`
   (ширина от 460 px, можно снять заново с телефона).
4. **Подпись** — сейчас её нет: страница говорит «я», но не называет имя.
   Если нужно, добавьте в блок `07` строку «Меня зовут …».

## Тон

Первое лицо, деловой тон: без канцелярита, но и без панибратства.
Конкретика вместо обещаний — цифры, сроки, ограничения. Ответы на неудобные
вопросы прямые, в том числе «а если вы пропадёте». Если правите текст,
держите этот тон: он и есть отличие от сайтов конкурентов.

## Структура

- `index.html` — разметка и весь текст
- `styles.css` — оформление (цвета и шрифты в `:root`)
- `app.js` — плавающая кнопка, валидация формы
- `assets/` — скриншоты

Шрифты системные: Georgia (текст и заголовки), Consolas (подписи),
Segoe UI (кнопки и форма). Ничего скачивать не нужно.
